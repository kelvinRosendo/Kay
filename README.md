# Kay
Ele permite conversar por voz, ativar o assistente dizendo “Kay”, fazer perguntas, consultar data e hora, abrir aplicativos como YouTube e Spotify e continuar funcionando em segundo plano por meio de um serviço nativo do Android. O projeto combina Flutter, reconhecimento de voz, síntese de fala, Vosk, Ollama e integração com o sistema Android.
